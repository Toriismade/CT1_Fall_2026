programming design system

“We are now in transition from an object-oriented to a systems-oriented culture. Here change emanates, not from things, but from the way things are done. ”

According to my research, in an object-oriented paradigm, progress is measured by accumulating better, newer, or more refined material items. In a systems-oriented paradigm, an object has little inherent meaning apart from the environment and network it participates in.

“What happens when we try to redefine the graphic design curriculum using a programming language as the tool for the designer? ”

Maybe from now on code isn't just a tool. It creates dynamic rules, letting machines actively shape changing designs rather than static layouts.

“Variations of a design can be tested much faster during the prototyping phase, and randomization can be used to reveal designs that the designer would never have created with a pencil. ”

Prototyping is much easier for a coder. And testing is so important.

What Do Prototypes Prototype

“The ways that we talk, and even think, about prototypes can get in the way of their effective use……to focus more attention on fundamental questions about the interactive system being designed: What role will the artifact play in a user's life? How should it look and feel? How should it be imple-mented? ”

Instead of focusing on tools or surface finish, we should ask what the product does, feels like, and how it works.

“Prototypes are not self-explanatory: looks can be deceiving. Clarifying what aspects of a prototype correspond to the eventual artifact—and what don't-is a key part of successful prototyping. ”

A prototype needs explanation since its polish can trick people into seeing a finished product.

“We define prototype as any representation of a design idea, regardless of medium. This includes a pre-existing object when used to answer a design question. ”

Anything is a prototype if you use it to test an idea and answer a design question.
